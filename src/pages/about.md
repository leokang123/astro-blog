강정훈입니다. 한양대학교 ERICA 컴퓨터학부를 졸업했고, 백엔드와 인프라, 데이터가 흐르는 과정을 공부하고 있습니다.

이 블로그에는 공부하면서 이해한 것들을 정리합니다. 운영체제, 네트워크, 데이터베이스, 알고리즘 같은 전공 지식부터 Docker, 홈서버, 웹호스팅, 개발 도구를 직접 다뤄본 기록까지 남겨두려고 합니다.

## 관심 있는 것

- 백엔드 시스템과 데이터 정합성
- Docker, Linux, 홈서버 운영
- 데이터베이스와 SQL
- 개발 과정을 줄여주는 작은 도구 만들기
- CS 전공 지식 정리

## 해본 것

- Programmers 문제 풀이를 VS Code 안에서 관리하는 확장 프로그램을 만들고 있습니다.
- Raspberry Pi, Docker, Tailscale을 활용해 개인 서버와 자동화 환경을 실험하고 있습니다.
- 여행 정산 앱을 만들며 금액 데이터의 수정, 삭제, 롤백 흐름을 다뤄봤습니다.
- 의료 폐기물 관리 플랫폼 프로젝트에서 업무 흐름을 파악하고 권한별 기능을 나누는 경험을 했습니다.
- 채팅 프로젝트를 진행하며 WebSocket, Redis, MySQL, 메시지 처리 구조를 공부했습니다.
