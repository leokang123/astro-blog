# 신기한 옵시디언 문법

#옵시디언

> 옵시디언 문법으로 벨로그에서는 다르게 보이는 것이 정상이다.
> 예를 들어, 각주나 admonition과 같은 커뮤니티 플로그인 등등..

## 각주

참조 [^1] 입니다. 두번째 각주 [^2] 입니다.

단어로도 할수 있습니다 [^3] 다만 편집모드에서만 이름으로 보이고
인라인 각주도 사용할수 있습니다^[따로 각주를 쓰러 갈 필요없이 여기서 인라인으로 처리할수 있습니다.]
각주는 전부 읽기 모드에서 숫자로 보입니다.

## 테이블

### Multi-Column

멀티컬럼 css스니펫을 적용한 후에 다음과 같이 사용할 수 있다
> 개인적으로 커뮤 플러그인 멀티 컬럼보다 웹사이트에서 찾은 css로 적용시킨 멀티컬럼이 여러므로 더 좋았다
> css적용후 admonition에 mutli-column이름 추가하면 더 편하게 사용가능

`````ad-multi-column
````ad-blue
```dataview
TABLE WITHOUT ID
link(file.path,file.name) AS "학습정리",
dateformat(file.mtime, "yyyy년 MM월 dd일 HH:mm") AS ""
FROM #학습정리 AND "Studied"
SORT 주제, series ASC
```
````

````ad-purple
```dataview
TABLE WITHOUT ID
link(file.path,file.name) AS "중요",
dateformat(file.mtime, "yyyy년 MM월 dd일 HH:mm") AS ""
FROM #중요 AND "Studied"
SORT 주제, series  ASC
```
````
`````
