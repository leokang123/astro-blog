# 출퇴근길에 읽는 은행과 금융 기초

은행 업무와 금융 현안을 이해하기 위한 개념 중심 글 모음이다. 용어를 한꺼번에 외우기보다 **의미, 작동 방식, 은행 업무와의 연결**을 순서대로 읽도록 구성했다.

한국은행, 금융위원회, 금융결제원, 예금보험공사, 고용노동부 등 공개 자료를 바탕으로 작성했다. 일부 개념은 은행의 공식 공시와 국제결제은행 자료로 보완했다. 각 글에 확인한 출처를 연결했다.

## 읽는 방법

한 번에 한 글만 읽어도 된다. 모르는 단어가 나오면 해당 장의 개념으로 돌아가고, 설명용 숫자는 실제 금리나 은행 실적으로 받아들이지 않는다.

금리·규제의 적용 한도처럼 자주 바뀌는 숫자보다 구조를 먼저 이해한다. 시행일을 적은 제도도 이후 변경될 수 있다.

## 자료의 범위

- 일반적인 은행 업무와 금융 개념을 설명한다. 특정 은행의 실제 내부 시스템을 공개하는 자료가 아니다.
- 예시는 이해를 위한 가정이며, 별도 표시 없이 특정 기업의 수치로 사용하지 않는다.
- 공식 자료와 학습을 위한 해석을 구분했다.
- 투자·대출·세무·법률에 관한 개인별 판단이나 상품 추천은 다루지 않는다.
- 면접 예상 질문과 답변 스크립트는 포함하지 않았다.
