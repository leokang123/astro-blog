# Personal Blog

A personal blog built with [Astro](https://astro.build/).

This project is customized from [AstroPaper](https://github.com/satnaing/astro-paper) by Sat Naing. The original theme is licensed under the MIT License.

## Structure

- `src/data/blog`: blog posts
- `src/assets/images`: post images
- `src/pages`: site routes
- `public`: static files

## Commands

```bash
pnpm install
pnpm run dev
pnpm run build
```
